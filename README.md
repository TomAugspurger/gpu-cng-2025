# GPU-accelerated Cloud-Native Geospatial

This repo contains the materials for [my talk](https://conference.cloudnativegeo.org/CNGConference2025#/agenda?day=2&lang=en&sessionId=126498000004395041) at the Cloud-Native Geospatial Forum in May, 2025.

See [Quadratic Means](quadratic-means.ipynb) for the demo.

[Install uv](https://docs.astral.sh/uv/getting-started/installation/) and run `uv sync` to reproduce the environment.
View the [slides](https://tomaugspurger.net/assets/gpu-accelerated-cng.pdf) for more.
